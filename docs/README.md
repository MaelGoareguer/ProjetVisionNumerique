# Documentation

Ce dossier contient toute la documentation technique du projet Vision Numérique.

## Fichiers Disponibles

### [Architecture](architecture.md)
Description détaillée de l'architecture du système, des composants principaux, des flux de données et des patterns de conception utilisés.

### [Méthodologie](methodology.md)
Documentation complète de la méthodologie de recherche, incluant l'état de l'art, les algorithmes utilisés, les optimisations et les protocoles d'évaluation.

### [Référence API](api_reference.md)
Référence complète de l'API publique, avec documentation de toutes les classes, méthodes et fonctions disponibles.

## Structure de la Documentation

La documentation est organisée pour répondre aux besoins de différents publics :

- **Développeurs** : Architecture et Référence API
- **Chercheurs** : Méthodologie et Architecture
- **Utilisateurs** : Voir le README principal à la racine du projet

Pour améliorer la documentation :
