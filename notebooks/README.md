## Utilisation

Pour utiliser ces notebooks, installez Jupyter :

```bash
pip install jupyter
```

Puis lancez Jupyter :

```bash
jupyter notebook
```

Ou utilisez JupyterLab :

```bash
pip install jupyterlab
jupyter lab
```
