# Images pour le Rapport

Ce dossier contient les images utilisées dans le rapport LaTeX.

## Images Requises

Pour que le rapport compile correctement, les images suivantes doivent être présentes :

1. **gestes_lecture_navigation.png** - Illustration des gestes de lecture (play/pause) et de navigation (avancer/reculer)

2. **gestes_volume_fullscreen.png** - Illustration des gestes de volume (volume up/volume down) et de plein écran (fullscreen)

## Note

La matrice de confusion (`confusion_matrix_20251204_202545.png`) se trouve à la racine du projet et est déjà référencée correctement dans le rapport.

## Format Recommandé

- Format : PNG ou JPG
- Résolution : 300 DPI minimum pour une bonne qualité d'impression
- Taille : Adaptée pour une largeur d'environ 0.48\textwidth dans LaTeX (environ 7-8 cm)
